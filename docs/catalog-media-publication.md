# Каталог и публикация медиа

## Владение каталогом

Товары, бренды, серии, фичи и их медиа относятся к единому мастер-каталогу.
Сейчас изменять его может только системный tenant MVN Buy с правом
`platform.manage`. Партнёрские tenant-менеджеры получают готовый каталог и
редактируют только свои коммерческие данные: цены, наличие, услуги, скидки и
настройки витрины.

Будущий доступ поставщиков должен добавляться отдельной моделью ограничений по
брендам или ассортименту поставщика. Само наличие товара в предложениях
поставщика не даёт права изменять мастер-каталог. До появления и проверки этой
модели поставщикам нельзя выдавать `platform.manage`.

## Публичный контракт изображений

Партнёрская витрина публикует только неизменяемые файлы из управляемого CDN:

- фотографии товаров: `https://cdn.mvn.by/products/shared/...` или
  `https://cdn.mvn.by/products/variants/original/...`;
- логотипы брендов, изображения фич и контент серии:
  `https://cdn.mvn.by/library/original/<sha256>.<ext>`;
- серия может использовать оба вида медиа, потому что её обложкой бывает как
  товарная фотография, так и самостоятельный контентный материал.

Произвольные внешние URL, старый префикс `https://cdn.mvn.by/media/...`,
обработанные временные варианты и URL с query/fragment не являются публичным
контрактом. Manager не должен сохранять их напрямую: внешний источник сначала
скачивается сервером, проверяется и записывается в соответствующую медиатеку.

При локальной разработке разрешены эквивалентные пути `/media/...` только когда
активен локальный провайдер хранения. Это исключение не действует для R2.

## SVG

SVG поддерживается для логотипов, иконок, фич и контента серии. При загрузке
сервер очищает SVG и отклоняет скрипты, обработчики событий, внешние ресурсы,
`foreignObject`, `iframe`, `object`, `embed`, DOCTYPE и сущности. Оригинал
сохраняется с расширением `.svg` и MIME-типом `image/svg+xml` в
`/library/original/`.

SVG не используется как фотография товара: товарный ingest декодирует исходник
и сохраняет общий WebP. Такой разный контракт намеренный.

## Гарантии при записи и отображении

Backend проверяет URL при сохранении товара, бренда, серии и фичи, а также при
назначении или копировании галереи. Готовность и публичный URL связанного
`MediaAsset` проверяются до публикации. Неверная конфигурация R2 останавливает
запись до создания ссылки в каталоге.

В партнёрском режиме витрина проверяет тот же узкий набор путей. Для серии она
перебирает обложку, галерею и изображения контентных блоков и показывает первый
допустимый вариант; один старый неверный URL больше не скрывает всю серию, если
в ней уже есть корректное изображение.

Эти проверки предотвращают новые расхождения. Существующие записи исправляются
только через отчёт и reviewed execute по
[процедуре исправления URL](product-media-url-backfill.md); внешние материалы
нельзя копировать без подтверждённого права на использование.
