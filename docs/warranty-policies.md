# Правила гарантии оборудования

Правила редактируются в Manager → Услуги → Оборудование → Правила гарантии.
Одно правило задаёт срок и условия для поставщика, бренда, нескольких серий
одного бренда либо конкретного товара. Поставщик может дополнительно ограничивать
правило бренда, серий или товара.

## Общее правило и исключения

Пример настройки, а не подтверждение условий поставщика:

1. Поставщик «Биоконд», бренд MDV, «Все серии», срок 36 месяцев.
2. Тот же поставщик и бренд, «Выбранные серии», отмеченный список серий,
   срок 48 месяцев.
3. Если отдельная модель внутри выбранной серии имеет другие условия,
   создать правило для конкретного товара.

Выбор правила: конкретный товар → выбранная серия → бренд → поставщик.
При одинаковой детализации правило с указанным поставщиком имеет приоритет
над правилом для любого поставщика. При полном совпадении детализации
сохраняется прежний порядок: более позднее создание, затем больший ID.
Неактивные правила и правила вне периода действия не участвуют в выборе.

Серии внутри одного правила объединены условием «любая из выбранных».
Поставщик, бренд и товар остаются дополнительными ограничениями.
В режиме «Выбранные серии» пустой выбор нельзя сохранить: он не должен
случайно расширить действие гарантии на весь бренд. Переключение на «Все серии»
явно снимает ограничение по сериям.

Регулярное ТО включается прямым переключением. Начальный интервал — 12 месяцев;
его можно изменить, например на 18. Снятие и повторная установка отметки
в открытой форме сохраняет введённый интервал. Исполнитель ТО и допустимое
опоздание показываются только при обязательном обслуживании.

## Совместимость и данные

API правил принимает `series_ids`; пустой массив явно очищает выбор.
При PATCH отсутствие поля сохраняет текущий выбор. Ответ содержит
`series_ids` и соответствующие им по порядку `series_titles`.
Поля одиночной серии `series_id`, `series_title`, `series_brand_id` сохранены
для совместимости. Связи с сериями хранятся в отдельной таблице;
миграция переносит туда существующие одиночные связи.

Проверяется существование каждой серии и принадлежность одному бренду.
Создание или изменение правила не пересчитывает уже зафиксированные
гарантии оборудования клиентов. Они являются снимками условий на момент
оформления и сохраняются независимо от последующего изменения правил.

## Последующее отображение на сайте

Витрина находится в отдельном репозитории `mvnby/mvn-web` и должна получать
готовые условия по HTTP от этого API. Изменение редактора правил само по себе
не публикует гарантийный срок на карточке товара.

Перед добавлением публичного поля нужно определить источник поставки товара:
одна модель у разных поставщиков может иметь разные условия. Нельзя автоматически
выбирать максимальный срок среди предложений или обещать гарантию поставщика,
который не участвует в продаже. Если источник не установлен и подходящего
общего правила нет, результат должен оставаться неизвестным.

Публичная проекция должна использовать тот же серверный выбор правила и отдавать
срок в месяцах, требование/интервал ТО, начало отсчёта и публичный текст условий.
Внутренние сведения о поставщике и закупке в публичный ответ не требуются.
На сайте клиенту следует показывать и срок, и существенные условия, например
«4 года при ежегодном ТО». Гарантия оборудования и гарантия монтажных работ
показываются отдельно.
