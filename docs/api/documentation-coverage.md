Дата: **7 октября 2026 года**. Исходный baseline: `main` **8a089914**;
этапы 2–3 продолжают результат **a3e79e89**. Это аудит схемы и исходников;

## Источник истины и точный перечень

Фактический контракт задают зарегистрированные FastAPI routes, зависимости
доступа, request/response models, сервисы и внешние middleware. Сохранённый
[OpenAPI](../../openapi.json) — производная схема, обновляемая
[штатной процедурой](../development-workflow.md#verification-by-change).
Детальные общие правила имеют один канонический контракт:
[доступ](authentication.md), [HTTP-соглашения](conventions.md),
[подпись/повторы витрины](../storefront-context-contract.md),
[бот](../bot-service-boundary.md), [OAuth/MCP](../chatgpt-connector.md).

[Точная инвентаризация](operation-inventory.json) содержит **609 операций**:
606 с путями `/api/*` и 3 well-known OAuth discovery. Строка включает метод и
полный путь, operation ID, наличие description в исходном baseline и номер
этапа проверки; записи сгруппированы по фактическому исходному файлу endpoint.
В формате `schema=2` поле `description_before` сохраняет исторический факт,
а `reviewed_stage` указывает на запись в `review_stages`. Это разные показатели:
ранее существовавшие описания тоже проверены по реализации.

MCP ASGI `/api/connector/mcp` и `tools/list` не входят в HTTP OpenAPI и эти
счётчики. OAuth discovery входит, `/login/*` и frontend/static routes не входят
в выбранную `/api` инвентаризацию. Внешнего supplier API нет; см.
[границы интеграции](supplier-integration-boundary.md).

## Критерий готовности операции

1. Назначение и наблюдаемый результат понятны потребителю, включая отличие
   чтения, preview, сохранения и запуска фоновой задачи.
2. Указаны фактическая аутентификация/роль, область данных и значимые проверки
   доступа. Общие правила связаны с каноническим документом. Внешние middleware
   не выданы за автоматически описанную security scheme.
3. Уточнены ограничения и исключения, которые неочевидны из моделей: например,
   200 с `error` в sync result, null вместо 404, частичный bulk, смена статуса
   при `mark_sent`, ограничения повтора/конкуренции. Только проверенные по
   реализации правила; поля и типы остаются в моделях.
4. Для мутации понятен безопасный повтор либо отсутствие receipt. Старый
   Manager POST не получает обещание Idempotency-Key от публичной витрины.
5. Ссылки работают, схема и клиент обновлены штатно, методы/пути/operation ID,
   request/response/security и runtime поведение не меняются ради документации.

Эти этапы не создают supplier credentials, endpoints или право внешнего
поставщика пользоваться платформенными Manager-маршрутами. Метаданные схемы
теперь описывают Kitlane/MVN и разные поверхности; сохранённое
`info.version=0.1.0` не обещает business semver. URL `v1` публичной витрины и
бота не означает версионирование Manager или MCP.

## Проверка дрейфа без проверки качества прозы

[test_api_documentation_inventory.py](../../tests/unit/test_api_documentation_inventory.py)
проверяет живую регистрационную карту без запуска lifespan/DB: точный набор
методов/путей, исходный файл, operation ID, непустой description у каждой
операции, указание этапа проверки и разрешение ссылок OpenAPI в репозитории.
Обычный unit CI запускает эту проверку; отдельного тяжёлого workflow нет.

```bash
.venv/bin/python -m pytest -q tests/unit/test_api_documentation_inventory.py tests/unit/test_public_write_openapi.py
```

Guard ловит потерю текста или дрейф перечня, **не оценивает полноту и истинность
прозы** и не присваивает новым операциям статус готовности. При добавлении или
удалении маршрута обновлять инвентаризацию и эту таблицу после проверки кода;
для новой операции сначала описать и проверить фактический контракт, затем
добавить запись и этап проверки. Не переносить старую отметку проверки на
изменившую смысл операцию без повторной сверки. Наличие baseline описания
сохранять отдельно от ручной проверки (новая операция получает `false`). Следовать
[проверке HTTP-схемы и клиента](../development-workflow.md#verification-by-change)
и обязательному CI; этот guard их не заменяет.
