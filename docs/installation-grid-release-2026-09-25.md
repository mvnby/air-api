# Новая сетка монтажа: состояние выпуска на 25 сентября 2026 года

По хендоффу `kitlane-handoff-2026-09-25.md` от 17:14 (Минск) согласованный
пакет выпущен и применён около 17:04. Основная компания, Polotsk и Test1
получили по самостоятельной опубликованной книге ревизии 1 с 20 тарифами.
Прежние 27 активных черновиков сохранены неактивными; исторические сметы и
документы не пересчитывались. Подробный операторский отчёт и артефакты
применения хранятся отдельно от репозитория.

Backend выпущен из коммита
[`4781dccd2d1cd2150fb1957af75f84d93bb86548`](https://github.com/mvnby/air-api/commit/4781dccd2d1cd2150fb1957af75f84d93bb86548),
web на всех трёх витринах — из
[`429d5f07f11b45d586a44a229e39b88ae978508a`](https://github.com/mvnby/mvn-web/commit/429d5f07f11b45d586a44a229e39b88ae978508a).
Хендофф фиксирует успешные [backend deployment](https://github.com/mvnby/air-api/actions/runs/36141864904),
[основную витрину](https://github.com/mvnby/mvn-web/actions/runs/36144509868),
[Test1](https://github.com/mvnby/mvn-web/actions/runs/36144556155) и
[Polotsk](https://github.com/mvnby/mvn-web/actions/runs/36144560468).

В хендоффе записаны 84 расчёта на опубликованных книгах, проверки блокировки
старых автоматических путей, отдельного scope партнёров и основных API
smoke-запросов. Проверка живой корзины основной витрины показала 880 BYN за
монтаж с насосом и 3330 BYN вместе с оборудованием; заказ не создавался.
Эти результаты относятся к состоянию на указанную дату, а не заменяют
повторную проверку текущего runtime.

Следующие действия: приёмка строк предложения и документов на реальном
рабочем объекте, проверка самостоятельности партнёрской сетки в изолированной
среде, отдельный перенос сифона G-35 и виброопор RF-V40P в конструктор опций.
Для менеджера действуют [правила новой сетки](installation-grid-manager-guide.md).
Новый запуск [процедуры применения](installation-grid-rollout.md) требует
нового плана; прежний подписанный план повторно применять нельзя.
