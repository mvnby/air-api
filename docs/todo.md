# ТЗ: Мульти-загрузка изображений в Админке (Статьи)

## 1. Контекст
Необходимо добавить возможность массовой загрузки изображений при редактировании статей (`Article`). Текущий функционал позволяет только вставку ссылок, но не загрузку файлов.
Цель: Ускорить процесс оформления статей, позволяя загружать пачку фото и сразу получать Markdown-код для вставки.

## 2. Backend (FastAPI)
- **Endpoint**: `POST /admin/api/upload_images`
- **Параметры**:
  - `files`: List[UploadFile] (Список файлов)
  - `slug`: Optional[str] (Слаг статьи для формирования пути сохранения)
- **Логика**:
  1. Принимает файлы.
  2. Определяет путь сохранения:
     - Если `slug` передан: `media/articles/{slug}/`
     - Если `slug` нет (новая статья): `media/articles/uploads/`
  3. Сохраняет файлы через `ImageService.save_image`.
  4. Возвращает список URL-адресов загруженных файлов.

## 3. Frontend (JS для Админки)
- **Файл**: `static/js/admin_article_upload.js`
- **Логика**:
  1. Скрипт должен активироваться только на страницах создания/редактирования статьи.
  2. Найти тулбар редактора Markdown (предположительно SimpleMDE/EasyMDE).
  3. Добавить кнопку "Мулти-загрузка" (иконка `fa-images`).
  4. При клике открывать диалог выбора файлов (`input type="file" multiple`).
  5. При выборе файлов отправлять их на `POST /admin/api/upload_images`.
  6. При успешной загрузке:
     - Сформировать Markdown код: `![](url)` для каждого изображения.
     - Вставить код в текущую позицию курсора редактора (CodeMirror) или в конец `textarea`.
  7. Обработать ошибки (alert при сбое).

## 4. Конфигурация
- Подключить скрипт в `admin/content.py` в классе `ArticleAdmin`:
  ```python
  extra_js = ["/static/js/admin_article_upload.js"]
  ```

## 5. Риски
- **Большие файлы**: Nginx/FastAPI могут иметь лимит на размер тела запроса. (Решение: проверить конфиг, если потребуется).
- **Дубликаты имен**: `ImageService` уже обрабатывает уникальность имен (UUID).
- **Новые статьи**: У новой статьи нет слага до сохранения. Файлы будут падать в общую папку `uploads`. (Приемлемо для mvp).
