# Мультисплит: аудит и границы первого релиза

27.09.2026. Этот документ фиксирует read-only аудит каталога и контракт первого релиза. Он не разрешает запись в production.

## Данные каталога

В публичной выборке `cat-multi` было 186 товаров: 46 наружных блоков, 138 внутренних, один `other` и один `unknown`. Только у пяти наружных TCL есть старые поля совместимости по slug/мощности, а у шести внутренних — обратные ссылки. Эти поля асимметричны и не содержат подтверждённой матрицы точных сочетаний, версии и статуса источника. Поэтому ни один текущий товар не получает автоматический статус `confirmed`.

До добавления проверенных профилей все видимые компоненты допускаются как **черновой состав для заявки**, но ответ говорит «Требуется проверка специалистом». Цена указана только за выбранное оборудование; возможные обязательные компоненты и монтаж не включены. Недоступный блок не заменяется автоматически. Данные о трассах и перепадах высот не проверяются.

## Серверный контракт

- `GET /api/v1/multi-split/options` и Manager-вариант возвращают отдельно опубликованные наружные и внутренние блоки `cat-multi` в tenant scope. Цены берутся из витринной проекции, `limit <= 100`.
- `POST /preview` принимает наружный блок и до восьми помещений с выбранными внутренними блоками. Возвращает состав, текущую цену оборудования, наличие по каждому блоку и статус. Публичный ответ не содержит закупку или маржу; Manager получает их отдельно.
- Только проверенный профиль с URL источника, версией источника, датой проверки, разрешёнными моделями и точной комбинацией моделей/количеств может дать `confirmed`. Вне проверенной комбинации статус `incompatible`. Отсутствующий/неполный профиль даёт `requires_specialist`.
- `POST /api/v1/multi-split/leads` сохраняет заявку с помещениями, статусом и снимком компонентов идемпотентно.
- При квалификации лида сохранённый снимок переходит в черновик предложения нового заказа. Его состав не подменяется текущими товарами; статус переводится в `requires_specialist` для повторной проверки перед продажей.
- Manager сохраняет один состав в один пустой черновик предложения или создаёт новую альтернативу. Снимок сохраняет цены на момент решения; повторная отправка с устаревшим preview отклоняется. Общий редактор заказа не может поменять состав блоков такого предложения. Новая конфигурация становится новым вариантом.

## Подтверждение матрицы

Оператор должен сверить точные SKU наружного и внутренних блоков с материалом производителя или дистрибьютора, допустимое число подключений и каждую комбинацию мощности, затем записать URL, версию документа, дату и проверяющего. Названия семейства и совпадение бренда не подходят. Текущие TCL ссылки требуют отдельной сверки суффиксов SKU; этот PR не создаёт подтверждённых профилей и не меняет production-данные.
